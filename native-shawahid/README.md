# «مصحف الشواهد» تطبيقًا مثبّتًا على الآيفون والآيباد

مثل تطبيقَي «المدرسة» و«مورد الظمآن»: غلاف أصلي (Swift) يعرض صفحة `mawrid/mushaf/` المنشورة، فكل تحديث للصفحة يصل التطبيق وحده، ويعمل دون إنترنت بعد أول فتح (وبعد «حفظ للعمل دون إنترنت»).

## التثبيت من الماك (مرة واحدة، ثم التجديد كل 7 أيام)

1. على الماك: Terminal ← `cd ~/mawrid && git pull` (أو حمّل المستودع من GitHub).
2. افتح `native-shawahid/Shawahid.xcodeproj` في Xcode.
3. اختر الهدف ← **Signing & Capabilities** ← Team: حسابك الشخصي (Personal Team)، وأبقِ Bundle Identifier: `com.khaledkadoum.shawahid`.
4. صِل الآيفون بالماك، واختره في أعلى Xcode، ثم ▶︎ (Run).
5. في الآيفون أول مرة: الإعدادات ← عام ← إدارة الأجهزة (VPN وإدارة الجهاز) ← وثّق حسابك.

- اسمه على الشاشة: **مصحف الشواهد**، وأيقونته خاصة به.
- الزر العائم «تطبيقاتي» فيه ينقلك إلى المدرسة وخزانتي ومورد الظمآن، ويعدّ أيام التجديد.
- رابط البيت وشروحه يفتح تطبيق «مورد الظمآن» المثبّت مباشرة على البيت.
